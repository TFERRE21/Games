# Games Online

Portal de jogos HTML5 para navegador, sem instalação.

## Conteúdo
- Arcade de plataforma
- Snake
- Tetris
- Corrida
- Memória
- Clicker
- Simulador de carro
- Simulador de voo

> O projeto usa jogos originais em HTML5/Canvas. Não inclui ROMs, BIOS ou arquivos de jogos comerciais.

## Executar
Abra `index.html` no navegador ou publique o repositório com GitHub Pages.

## Publicação no GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root).
